Keyword Cipher

The most powerful cipher yet â€” because the key isn't a number, it's a whole codebook. Learn to parse it, search it, and use it to swap words in a message.

The Codebook Concept

The Caesar cipher shifts every letter by the same amount â€” anyone who knows the rule and the shift can break it. The Keyword cipher is different: instead of shifting letters, you swap entire words using a secret codebook.

The codebook is a list of pairs: real word,code word. To encode a message, you look up each word. If you find it, replace it. If you don't, leave it as-is.

dog,bravo
cat,alpha
run,delta
meet,foxtrot
tonight,sierra
at,tango
the,november
park,lima

Example encoding:

"Meet the dog at the park"
→
"foxtrot november bravo tango november lima"

The codebook is the secret key. Two people can send "foxtrot november bravo tango november lima" and anyone intercepting it just sees words â€” unless they have the codebook.

To decode: do the same lookup in reverse. Find the code word in the right column, replace it with the real word in the left column.

Java Concepts You'll Use

split(",") â€” Different Delimiter

You already used split(" ") to split on spaces. You can split on any character â€” the codebook uses commas.

// parts[0] is "dog"   â€” the real word
// parts[1] is "bravo" â€” the code word
dog parts[0]
bravo parts[1]

equals() â€” The Right Way to Compare Strings

Here's a trap almost every Java beginner falls into: using == to compare Strings.

String word = "hello";

// WRONG â€” this often fails even when strings look identical
if (word == "hello") { ... }

// RIGHT â€” always use .equals() for String comparison
if (word.equals("hello")) { ... }

== checks if two variables point to the exact same object in memory. .equals() checks if they contain the same characters. For Strings, you almost always want .equals(). Just make it a habit â€” it will save you hours of confusing bugs.

Pass-Through Logic

What happens if a word isn't in the codebook? Nothing â€” you just keep the original word.

String encodedWord = word;   // default: unchanged

for (String entry : codebook) {
    String[] parts = entry.split(",");  // split into [real, code]
    if (word.equals(parts[0])) {        // found a match?
        encodedWord = parts[1];         // use the code word
        break;                          // no need to keep searching
    }
}
// encodedWord is now either the swap or the original â€” both cases handled
